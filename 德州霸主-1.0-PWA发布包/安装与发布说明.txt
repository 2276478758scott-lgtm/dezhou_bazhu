德州霸主-1.0 · PWA 发布包

包含最新十种 AI、分别设置初始筹码、情绪与台词调整、本地策略助手、存档和离线缓存。全部推理在设备内运行，无模型 API 或云端计算。

一、发布
1. 解压本包，把所有文件原样上传到同一个 HTTPS 静态网站目录。
2. index.html 必须位于该目录首页；不要只上传独立 HTML 或漏掉 worker.js、sw.js、图标和其他脚本。
3. 保持文件名与相对路径不变。不需要安装 npm 依赖，也不需要后端程序。
4. 网站应能正常返回 JavaScript 文件，manifest.webmanifest 推荐使用 application/manifest+json 类型；sw.js 不应被重定向到其他域名。
5. 本包不自动更新此前的 chatgpt.site 网址。

二、iPhone / iPad 安装
1. 用 Safari 打开发布后的 HTTPS 网址。
2. 等待页面显示“离线资源已缓存”。第一次必须联网。
3. 点 Safari 的分享按钮，选择“添加到主屏幕”，然后从主屏幕图标进入。
4. 安装后打开一次，再开启飞行模式检查能否进入游戏。
5. ZIP 本身不是可直接安装的 iOS 应用，也不是 IPA；在“文件”应用里打开网页不能替代上述安装步骤。

三、存档和更新
- 刷新或重新进入后会恢复本机存档并暂停，点“继续”才推进牌局。
- Safari 网站数据与主屏幕应用的存储可能相互独立，首次进入主屏幕应用应检查存档；不要承诺跨入口共享。
- 更换网站地址、删除网站数据或系统清理缓存可能导致存档和离线资源丢失。
- 本包离线缓存版本：dezhou-bazhu-pwa-v4。旧版本用户在本手结束后点击“更新离线版本”。
- 以后发布新的代码时要更新 sw.js 的缓存版本，确保所有资源一起更新。
