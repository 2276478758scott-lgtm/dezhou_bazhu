# 德州霸主 2.0 · 离线缓存 v27

完整功能与 GitHub Pages 更新说明见 [2.0使用与更新说明](2.0使用与更新说明.md)。

十五种 AI、四桌锦标赛、持久冠军资金与自选 Pokerface 大奖赛、宿敌与统一发言、交互图表、回放和故事 JSON／Markdown 导出。全部本地运行，无 npm 运行依赖，无后端或模型 API。

- npm test：自动测试，当前 160 项通过。
- npm start：本机开发服务器。

旧 coach.js 仅用于已有兼容性测试，不被游戏或 PWA 加载；现役助手使用 helper.js 和本地抽样策略，不下载语言模型。内核升级说明保留 v11 基础实现的历史说明，当前版本以 2.0 使用说明为准。
