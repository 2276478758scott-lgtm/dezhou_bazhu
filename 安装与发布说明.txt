德州霸主-1.0 · 当前 v10 PWA 发布包

发布：解压后，把里面的全部文件上传到原 GitHub 仓库最外层，覆盖同名文件。index.html 位于发布目录首页；不要只上传 HTML、ZIP 或额外套一层文件夹。本版新增 pokerface.js，也要上传。无需 npm 依赖或后端。

更新：等 GitHub Pages 发布完成后，刷新原游戏网址，在游戏设置内点击“更新离线版本”，当前一手结束后再更新。缓存版本 dezhou-bazhu-pwa-v10。

iPhone 安装：Safari 打开 HTTPS 网址，等待“离线资源已缓存”，通过分享菜单添加到主屏幕。首次需要联网，后续可离线使用；系统清理网站数据可能清除存档。

新功能：开局可选 Pokerface，三个角色及趣味昵称分别随机抽取；隐藏角色但保留情绪标签，整场结束或重开后揭晓。情绪阶段、角色差异、下注行为和台词已调整。

存档：旧版默认普通模式，原网址与存档键保持不变。刷新恢复后暂停，点继续才推进。战绩保存在本机，重开不清空历史。不使用模型 API、云端推理或后端。

验证：93项自动测试、六种Chromium手机视口检查和离线重载检查通过。iPhone Safari真机尚未验收。详细功能见“执行版使用说明.md”。
